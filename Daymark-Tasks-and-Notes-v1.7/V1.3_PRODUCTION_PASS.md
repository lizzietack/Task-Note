# Daymark v1.3 production pass

- Calendar days are interactive: clicking any date opens a new task pre-filled for that day.
- Calendar task chips open the existing task editor; monthly task list is editable too.
- Added Today calendar jump, overflow counts, keyboard interaction, and empty-month guidance.
- Quick Capture now exposes Auto / Task / Note choice and a real schedule control with Today, Tomorrow, date and time.
- Detailed Task from Quick Capture carries the parsed title/date/time into the editor.
- Task list classification stays consistent when dates change.
- Repeating tasks now generate their next occurrence when completed.
- Task deletion requires confirmation.
- Subtask + Add is fully interactive and mirrors Enter behavior.
- Search now covers subtasks, dates, checklist items and attachment filenames.
- Existing note attachments, voice recording, checklist editing and click-to-edit behavior remain intact.
- PWA/offline shell is configured for production builds.

Known platform boundary: browser-level reminder fields are stored and editable, but true background OS alarms require notification scheduling support in the installed PWA/native layer.
